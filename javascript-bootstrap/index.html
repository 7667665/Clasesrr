JavaScript permite que una página responda a clics, escriba mensajes y cambie contenido.

PRUÉBALO AQUÍ

HTML

<button onclick='alert("¡Hola!")'>Saludar</button>

JavaScript

alert('¡Hola!');

💡 alert() abre un mensaje del navegador.

PRUÉBALO AQUÍ

Título original

HTML

<h3 id='titulo'>Título original</h3><button class='btn btn-warning' onclick='cambiarTitulo()'>Cambiar título</button>

💡 innerText cambia el texto visible.

Botón 6: fecha y hora

JavaScript puede consultar la fecha y hora del dispositivo.

PRUÉBALO AQUÍ

HTML

<button class='btn btn-dark' onclick='mostrarFecha()'>Ver fecha</button><p id='fecha'></p>

Botón 7: contador

Una variable guarda un valor que cambia con cada clic.

PRUÉBALO AQUÍ

0

HTML

<h3 id='contador'>0</h3><button class='btn btn-secondary' onclick='aumentar()'>Sumar +1</button>

JavaScript

let numero=0; function aumentar(){ numero=numero+1; document.getElementById('contador').innerText=numero; }

💡 let crea una variable; cada clic suma uno.

Botón 8: cambiar imagen

La propiedad src indica qué imagen aparece.

PRUÉBALO AQUÍ

HTML

<img id='imagen' width='220' src='https://placehold.co/300x150/222/fff?text=Imagen+1'><button class='btn btn-primary' onclick='cambiarImagen()'>Cambiar imagen</button>

JavaScript

let foto=1; function cambiarImagen(){ foto=foto===1?2:1; document.getElementById('imagen').src='https://placehold.co/300x150/222/fff?text=Imagen+'+foto; }

💡 Cambiamos el atributo src desde JavaScript.

Botón 9: saludo personalizado

El valor escrito en un input puede utilizarse en JavaScript.

PRUÉBALO AQUÍ

HTML

<input id='nombre' class='form-control' placeholder='Tu nombre'><button class='btn btn-success' onclick='mostrarNombre()'>Saludar</button><p id='resultado'></p>

JavaScript

function mostrarNombre(){ let nombre=document.getElementById('nombre').value; document.getElementById('resultado').innerText='¡Bienvenido, '+nombre+'!'; }

💡 value lee el texto del campo.

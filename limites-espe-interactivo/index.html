Hallazgo 02 · Idea intuitiva

Un límite habla de
acercarse.

El límite es el valor al que se aproxima una función cuando la variable se acerca a un número determinado.

No preguntamos necesariamente cuánto vale en el punto, sino hacia dónde se dirige.

x → 2
123
x = 1
Notación matemática · 03 / Explicación interactiva

¿Por qué el límite
es 5?

Nuestra regla es f(x) = x + 3: a cada número le sumamos 3. Si x se acerca a 2, el resultado se acerca a 2 + 3 = 5.

lim (x → 2) (x + 3) = 5

Haz clic para acercarte a 2 sin tocarlo:

1+ 3 =4

Paso 0: 1 + 3 = 4. Todavía estamos lejos de 5.

La noticia matemática
4 → 5

Cada vez que x se aproxima más a 2, x + 3 se aproxima más a 5.

En esta animación nunca usamos x = 2. El límite es 5 porque los resultados se aproximan a ese valor desde ambos lados.

El concepto que sorprende · 06

¿Y si hay un
hueco en la gráfica?

Considera la función (x² − 4)/(x − 2), que no está definida en x = 2.

Sin embargo, para x distinto de 2, es igual a x + 2.

¡El límite es 4 aunque la función no esté definida en x = 2!
